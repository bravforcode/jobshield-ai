# JobShield AI — Implementation Plan

> **For agentic workers:** subagent-driven development was attempted; see
> [Notes on Execution](#notes-on-execution) below. The build was finished
> in-session after the parallel agents hit step/token limits.

## Goal
Implement the JobShield AI Thai Occupation Mobility Network per
`docs/jobshield-ai-spec-v2.md`. 18 occupations, PPMI skill graph, Dijkstra
path-finding with two-layer cost split, wage radar with centrality-based
underpayment detection, single-page web UI.

## Architecture
```
[job postings] -> [LLM extract] -> [PPMI Skill Graph]
                                    |
                                    v
                  [Occupation Vectors] -> [Occupation Distance]
                                    |
                                    v
                 [Transition Graph] -> [Dijkstra Layer 1]
                                    |
                                    v
                      [Layer 2: rank with wage + risk]
                                    |
                                    v
                          [Wage Radar: centrality]
```
- `py/` — Python core (uv, ruff)
- `ts/` — TypeScript API + web (bun, biome)
- `data/mock/` — 18 occupations × ~8-12 postings = 153 postings

## Tech Stack
- Python 3.12, uv, ruff
- TypeScript 5.6, Bun 1.3, Biome 1.9
- No web framework (vanilla TS) for the demo
- Zero new deps beyond the stdlib

## Run

```bash
# 1. Generate mock data (one-time)
cd py && uv run python -m jobshield.data.mock_data

# 2. Build artifacts
cd py && uv run python -m jobshield.cli.build --mock

# 3. Run all tests
cd py && uv run pytest -q            # 83 tests
cd ..  && bun test                    # 5 tests

# 4. Start the API + web
JOBSHIELD_ARTIFACTS="C:/jobsume/data/artifacts.json" \
  bun run ts/api/src/index.ts         # http://localhost:3000
```
